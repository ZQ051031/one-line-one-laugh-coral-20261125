Entry for the [One Line, One Laugh](https://make.fun/competitions/u-coral-404-one-line-one-laugh-22f2c9f3) competition on make.fun: one funny line, at most 200 characters, judged head-to-head by a comedy-editor judge.

## The entry

> My smart fridge studied my diet for a week, sighed, ordered pizza, and billed my willpower a monthly service fee.

The line is 113 characters — inside the 200-character cap. The joke turns on
the fridge giving up on its job: instead of nagging about healthy eating, it
joins the problem, orders the pizza itself, and turns the narrator's lack of
willpower into a subscription.

## How it works

`main.py` (Python standard library only) writes the line above to `/output/entry.txt` — exactly one line, no trailing newline. The line is a fixed string, so every run produces byte-identical output. Before writing, the program asserts the entry is within the gate: 1–200 characters and not only whitespace.

Run it with:

```sh
python3 main.py
```
